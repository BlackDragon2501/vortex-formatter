# Vórtex Formatter

Vórtex Formatter, de Vortex Company: caja de herramientas para developers — formatea y valida JSON con estadísticas, minifica, ordena claves, convierte Base64/Base64-URL, decodifica URLs y JWT (solo inspección), y calcula hashes MD5 (implementación propia) y SHA-1/256/384/512 (Web Crypto). Todo se calcula en tu navegador. Gratis, sin anuncios y 100% local.

## Stack

- Next.js 16 + React 19 + Tailwind 4 + TypeScript
- Parser JSON propio, Web Crypto nativa y MD5 en TypeScript puro
- 100% local en el navegador, sin backend y sin variables de entorno

## Desarrollo

```bash
bun install
bun run dev
```

## Producción

```bash
bun run build
```
